# Changelog

## 1.1.0 — release candidate

- Improved the workspace layout: new cards open beside the editor, card settings start collapsed, and **Reset UI** restores a useful arrangement.
- Kept task checkboxes interactive in the workspace and HUD, with changes saved to the correct global or world/server context.
- Improved recovery from interrupted writes using a temporary file and previous complete backup.
- Added separate Fabric builds from Minecraft 1.20.1 through 1.21.11 and 26.1 through 26.3. Live compatibility claims are limited to the exact versions in `docs/TESTING.md`.
